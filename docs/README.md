# Documentation Layout

The documentation is now organized by scan domain:

- `docs/pii`
  - PII and CRDP assessment, support-estimating, and PII-focused marketing material
- `docs/pqc`
  - PQC scanner design, glossary, CBOM and vendor-family maintenance, wrapper onboarding, Swagger draft examples, vendor references, and PQC marketing material

Use `docs/pii` for sensitive-data migration and CRDP-oriented material.
Use `docs/pqc` for post-quantum-readiness and crypto-migration material.

Helpful explainers:

- `docs/pii/how-the-pii-scanner-works.html`
- `docs/pqc/how-the-pqc-scanner-works.html`
